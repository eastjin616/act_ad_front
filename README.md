# act_ad_front

영상 콘텐츠 제작 인력을 모집하고 지원할 수 있는 `act_ad`의 앱인토스 미니앱 프론트엔드 저장소입니다.

## 문제 정의

영상 콘텐츠 제작 현장에서는 필요한 인력을 구할 때 카카오톡과 같은 메신저로 공고를 전달하는 경우가 많습니다. 공고 형식이 일정하지 않고, 제작 단계별로 필요한 인력과 준비 상황을 한 번에 파악하기 어렵습니다.

`act_ad`는 흩어진 제작 공고와 지원 정보를 카드 형태로 구조화합니다. 배우, 스태프, 엔터테인먼트 회사가 모바일에서 제작 정보를 확인하고 필요한 팀을 빠르게 찾을 수 있도록 돕습니다.

## 주요 사용자

| 사용자 | 필요한 기능 |
|---|---|
| 배우 | 필모그래피 등록, 출연 공고 탐색, 지원 |
| 촬영·조명·미술·제작 스태프 | 팀별 공고 탐색, 경력 등록, 지원 |
| 엔터테인먼트 회사 및 제작사 | 작품 정보 등록, 제작비와 기간 설정, 팀별 모집 공고 등록 |

## As-Is / To-Be

### As-Is

- 구인·구직 공고를 카카오톡 등 메신저로 공유한다.
- 공고 형식이 일정하지 않아 필요한 정보를 다시 확인해야 한다.
- 제작 기간에 필요한 팀, 장비, 테스트 촬영, 미술 준비 상황을 한 화면에서 보기 어렵다.

### To-Be

- 제작사가 프로젝트 공고를 카드 형태로 등록한다.
- 사용자는 역할별 모집 현황과 제작 일정을 모바일에서 확인한다.
- 배우와 스태프는 필모그래피 또는 경력을 등록하고 지원한다.
- 제작사는 프리프로덕션 진행 상황을 한 화면에서 확인한다.

## 핵심 기능

### MVP

- 프로젝트 공고 카드 목록
- 프로젝트 상세 정보
- 배우 및 스태프 역할별 모집 공고
- 필모그래피 또는 경력 등록
- 공고 지원
- 역할, 촬영 기간, 지역 기준 필터

### 이후 검토

- 프리프로덕션 체크리스트
- 팀별 모집 진행 현황
- 장비 및 테스트 촬영 일정 관리
- AI 기반 성향 분석과 역할 추천

## 예시 시나리오

엔터테인먼트 회사가 제작비 3,000만 원, 제작 기간 3개월인 영상 콘텐츠 프로젝트를 등록합니다. 이후 촬영팀, 미술팀, 제작팀, 조명팀 공고를 각각 올리고 지원 현황을 확인합니다.

예시 팀 구성:

| 구분 | 담당 |
|---|---|
| 엔터테인먼트 회사 | Hash |
| 촬영팀 | 전창용 |
| 미술팀 | 이호석 |
| 제작팀 | 서동진 |

## 참고 서비스

- 당근: 모바일 중심의 카드형 탐색 경험
- 채용 서비스: 이력서 등록, 공고 검색, 지원 흐름
- 필름메이커스: 영상 제작 관련 구인·구직 공고
- 플필: 배우 프로필 및 캐스팅 공고

## 브랜치 운영 규칙

| 브랜치 | 용도 |
|---|---|
| `main` | 운영 브랜치. 배포 가능한 상태만 반영 |
| `develop` | 개발 통합 브랜치. 기능 및 수정 작업은 이 브랜치를 기준으로 진행 |
| `feature/<브랜치명>` | 신규 기능 개발 |
| `fix/<브랜치명>` | 버그 수정 |

### 작업 흐름

1. 작업 시작 전에 `develop` 브랜치를 최신 상태로 갱신한다.
2. 작업 목적을 알아볼 수 있도록 `feature/<브랜치명>` 또는 `fix/<브랜치명>` 형식으로 로컬 브랜치를 생성한다.
3. 작업이 끝나면 `develop` 브랜치를 대상으로 Pull Request를 생성한다.
4. 운영 반영 시에는 검증된 `develop` 변경사항을 `main` 브랜치에 병합한다.

```bash
git switch develop
git pull origin develop
git switch -c feature/project-card-list
```
