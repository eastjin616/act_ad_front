## 1. 선정 원칙

첫 제품은 아래 조건을 우선한다.

1. 사용자가 반복적으로 겪는 문제를 해결한다.
2. 핵심 사용 행동을 한 문장으로 설명할 수 있다.
3. 3명이 5주 안에 MVP를 구현할 수 있다.
4. 앱인토스 안에서 바로 실행하는 흐름과 잘 맞는다.
5. 결제, 민감정보, 복잡한 운영이 없어도 첫 버전이 성립한다.

### 이번 MVP에서 제외할 범위

- 결제가 있어야 성립하는 서비스
- 실시간 채팅 또는 커뮤니티 운영이 핵심인 서비스
- 금융, 의료 등 민감정보 처리가 핵심인 서비스
- 복잡한 관리자 페이지가 필수인 서비스
- 외부 심의 또는 복잡한 권한 처리가 필요한 서비스
