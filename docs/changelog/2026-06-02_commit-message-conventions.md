# 커밋 메시지 규칙 추가

## 배경

커밋 목록만 보고도 작업 종류와 영향을 받는 영역을 빠르게 파악할 수 있도록 팀 공통 제목 형식이 필요했다.

## 구현 방식

- 커밋 제목을 `<type>(<scope>): <한글 설명>` 형식으로 작성하도록 README에 기록했다.
- `feat`, `fix`, `refactor`, `docs`, `test`, `chore` type의 용도를 정리했다.
- 프론트엔드에서 자주 사용할 `web`, `miniapp`, `ui`, `repo`, `changelog` scope 예시를 추가했다.

## 핵심 결정

- 제목 설명은 한글로 작성한다.
- 작업 종류와 범위는 영문 `type`과 `scope`로 일관되게 표시한다.

## 영향 범위

- README
- 이후 생성되는 Git 커밋 제목

## 검증 내용

- README의 제목 형식, type 표, scope 예시, 커밋 예시가 서로 일치하는지 확인했다.

## 남은 리스크

- CI에서 커밋 제목 형식을 자동 검사하지는 않는다.
